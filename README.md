# PeteCast

A general-purpose Google Cast receiver: show any web page — or a built-in Now Playing screen — on a TV, Chromecast or Nest Hub.
Built on the current Cast Application Framework; DashCast-compatible.

- **Cast App ID:** `61ADD7C7` (published)
- **Receiver:** https://c-i-x-e-l.github.io/petecast/
- **Try it:** https://c-i-x-e-l.github.io/petecast/send.html (desktop Chrome)
- **Channel:** `urn:x-cast:petecast` — e.g. `{"type":"navigate","url":"http://192.168.1.20:8080/"}`

Full protocol, Android/Python helpers and integration guide: the PeteCast kit (`PROTOCOL.md`, `README.md`).
